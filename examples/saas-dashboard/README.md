## Notable Patterns & Techniques

### Multi-Tenant Security
```typescript
// Authorization check before data access
const hasPermission = await checkWorkspacePermission(
  ctx.db,
  ctx.session.userId,
  invitation.workspace_id,
  'manage_members'
);

if (!hasPermission) {
  throw new TRPCError({ code: 'FORBIDDEN' });
}
```

### Race Condition Prevention
```sql
-- Unique constraint prevents duplicate invitations
CREATE UNIQUE INDEX idx_workspace_invitations_unique_active
ON workspace_invitations(workspace_id, email)
WHERE deleted_at IS NULL AND accepted_at IS NULL;
```

### Expand-Contract Migrations
From PROMPTKIT.md:
```
Phase 1 (Expand): Add new column as nullable, dual-write
Phase 2 (Migrate): Backfill data, switch reads to new column
Phase 3 (Contract): Drop old column after zero references
```

### Monorepo Workspace Scoping
```bash
# Never run unbounded root commands
pnpm test  # ❌ Runs ALL packages, slow and noisy

# Always scope to active workspace
pnpm --filter @workhub/web test  # ✅ Fast, focused
pnpm --filter @workhub/api test
```

## Lessons from the Code Review

### Critical Security Issues Caught
1. **Authorization Bypass**: Missing workspace permission check allowed cross-tenant data manipulation
2. **Race Condition**: Non-atomic duplicate check + insert vulnerable to TOCTOU

### Performance Issues Identified
3. **N+1 Query**: Member list triggered 51 queries instead of 1 (solved with Drizzle relations)

### Accessibility Gaps
4. **Missing ARIA**: Form inputs lacked labels and error associations (WCAG 2.2 Level A violation)

### Clean Patterns Praised
5. **Discriminated Unions**: Type-safe error handling throughout API layer
6. **Shared Zod Schemas**: Client and server validation from single source of truth
