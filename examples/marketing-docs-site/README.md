# Example: Marketing and Documentation Website

A small Astro and Tailwind site for a product launch, documentation, and support content.

> **Illustrative composite — Level 1:** This example models a localized quality improvement using inline planning, scoped implementation, and verification. It intentionally has no canonical Task Record.

## PromptKit focus

- `pk:design`: Establish tokens, responsive rules, and anti-slop constraints.
- `pk:review`: Audit semantics, keyboard access, and content structure.
- `pk:perf`: Measure Core Web Vitals and asset budgets.
- `pk:test`: Verify navigation, forms, and critical responsive states.
