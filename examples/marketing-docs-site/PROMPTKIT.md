# Project Profile: Launch Docs

## Stack

Astro, TypeScript, Tailwind CSS, MDX, Playwright, and Lighthouse CI.

## Active commands

```bash
npm run dev
npm test
npm run lint
npm run build
npm run lighthouse
```

## Guardrails

- Semantic HTML is the default.
- Every interactive control is keyboard accessible.
- Content remains readable without client-side JavaScript.
- Images and third-party scripts have explicit performance budgets.
- WCAG 2.2 AA and Core Web Vitals are release checks.
