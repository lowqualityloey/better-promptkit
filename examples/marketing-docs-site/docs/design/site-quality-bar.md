# Site Quality Bar

## Design

- Use a small token set for color, spacing, type, and focus states.
- Prefer semantic HTML and content-first layouts.
- Avoid animation that blocks reading or keyboard navigation.

## Accessibility

- Every form control has a visible or programmatic label.
- All interactive elements are keyboard reachable with visible focus.
- Text and controls meet WCAG 2.2 AA contrast requirements.

## Performance

- Track LCP, INP, and CLS on representative mobile pages.
- Keep third-party scripts opt-in and defer non-critical assets.
- Verify image dimensions, responsive sources, and compressed output before release.
