## Public contract impact and migration guidance

This is an additive minor release. Existing Task Records, artifacts, workflows, and initialized projects remain valid; no migration is required. `pk:fix` is an additional remediation workflow for known findings and does not replace `pk:debug`, `pk:review`, `pk:commit`, or `pk:ship`. Existing users may adopt the new workflow incrementally. The PowerShell initialization changes preserve existing directive behavior while making malformed or duplicate marker states fail safely.
