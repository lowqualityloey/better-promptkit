# Better-PromptKit v1.1.1 — Safe, Non-Destructive Initialization Updates

## Highlights

- Fixed a safety issue in `init.sh` that could overwrite an entire existing agent configuration if directive replacement failed.
- Added regression coverage for preserving user instructions and rejecting malformed directive markers.

## What changed

- `init.sh` now validates directive markers before updating an existing agent file.
- Directive updates are generated in temporary files and moved into place only after successful transformation.
- Existing content outside the PromptKit markers is preserved.
- Malformed or incomplete marker blocks fail loudly without modifying the original file.
- The safety regression suite runs in CI.

## Migration guidance

No migration is required. Existing Task Records, artifacts, workflows, and initialized projects remain compatible. If a prior initialization attempt failed, rerun the normal `init.sh` or `init.ps1` command after updating to `v1.1.1`.

## Verification

- Init safety regression tests passed locally.
- Bash and PowerShell behavioral-contract tests passed.
- Bash and PowerShell reference validators passed.
- Strict Level 2 and Level 3 execution-control validation passed.
- GitHub Actions passed on Linux and Windows for the release candidate.

## Compatibility and boundaries

This is a corrective instruction-layer release. It does not change task ceremony levels, workflow routing, or existing artifact formats. The fix prevents data loss during initialization updates and makes malformed-marker failures explicit.
