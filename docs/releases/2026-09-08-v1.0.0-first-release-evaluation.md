## 3. Preliminary Version Rationale

The preliminary candidate is `1.0.0` because:

1. No prior approved Better-PromptKit release, version source of truth, or Git tag exists.
2. The current committed repository exposes a coherent public instruction-layer contract through workflows, protocols, templates, initialization scripts, and documentation.
3. The candidate is intended to represent the first public release of that current contract, not the future Agent Execution Control feature.
4. The reviewed public surface is additive overall: it adds workflow, protocol, template, documentation, and cross-platform setup guidance, with the PowerShell validator change classified as corrective and no application/runtime migration.

This rationale is preliminary. QA/Reviewer and the Release Coordinator SHALL confirm whether the current surface is mature enough for a `1.0.0` release or whether the project should explicitly use a pre-1.0 baseline instead.
