## Public contract impact and migration guidance

This is an additive minor release. Existing Task Records and artifacts remain valid; no migration is required. Localized bug fixes and small isolated source changes may now follow Level 1 with inline planning and verification rather than requiring `docs/tasks/<task-id>.md`. Schema/data migrations, authentication/authorization, breaking public contracts, multi-component architecture work, and meaningful risk remain Level 2. Tags, releases, publication, deployments, and high-impact contract changes remain Level 3 and still require release evidence plus explicit human authorization.
