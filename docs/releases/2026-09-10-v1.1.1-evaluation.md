## Public contract impact and migration guidance

This is a corrective patch release. Existing Task Records, artifacts, initialization outputs, and PromptKit workflows remain valid; no migration is required. The fix prevents an initialization update failure from erasing user-owned agent instructions. Consumers should rerun their normal initializer if they previously encountered a failed directive update; no manual artifact migration is needed.
